# Skill: docs-governanca

Use esta skill quando a tarefa envolver atualização, auditoria ou reorganização dos documentos base.

## Regras

- CEREBRO_PROJETO.md: decisões permanentes.
- STATE.md: estado atual real.
- CODEX_RESULTADO.md: registro cronológico do executado.
- ROADMAP_FINANCEIRO.md: pendências e próximos passos.
- Não apagar histórico útil.
- Preferir ajustes cirúrgicos.
