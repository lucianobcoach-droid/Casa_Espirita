# Skill: financeiro-regras

Use esta skill para qualquer alteração no módulo financeiro.

## Regras

- Não alterar cálculos financeiros sem pedido explícito.
- Preservar receita, despesa e transferência.
- Transferências internas não inflam receitas/despesas operacionais.
- Data de pagamento é a referência operacional principal.
- Rateios devem ser preservados.
- Conta destino é obrigatória em transferências.
